# Poisson Disk Sample

If you want to make sure the surface triangle indexes of sampled particles are consistent with the surface triangle indexes generated by *tetgen*, you need to generate `.obj` with the following step.

1. Get the tetgen file of the model (`.ele`, `.face`, `.node`)
2. Run *tool_save_obj_from_tet* target with your tet model name. (the target is in the `examples` folder)

Once you get an `.obj` file, you can follow the instruction below to get the sample particles.

1. Open the `.obj` with *MeshLab*
2. `Filters -> Quality Measure and Computations -> Compute Geometry Measures`. This will calculate the bounding box of the model, which will help you to decide the distance of the sampled particles. The result will be shown in output widget at bottom right.
3. `Filters -> Sampling -> Possion-disk Sampling`. Fill the `Explicit Radius` with the desired distance and `Apply`.
4. `Filters -> Sampling -> Vertex Attribute Transfer`. Set `Target Mesh` to the sampled point cloud. Set `Source Mesh` to the origin mesh model. Select the `Save barycentric coords` box.
5. Save the sampled particle layer model as `xxx.sample.ply`. Unselect the `Binary encoding` box. Select the `NearestFaceIndex` and `BarycentricCoords` box.
